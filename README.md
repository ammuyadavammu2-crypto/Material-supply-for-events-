# Food Material Supply for Events

A simple event food supply website using HTML, CSS and JavaScript.

## Files
- index.html
- menu.html
- booking.html
- contact.html
- css/style.css
- js/menu.js
- js/booking.js
- README.md

## How to run
Open `index.html` in a browser.

## Features
Food catalogue, quantity selection, automatic total calculation, booking form, validation and localStorage.
